# NEO-TEST 2026 // 最新测试合集

NEO-TEST 是一个采用轻量化黑白极简主义（Monochrome）美学设计的在线多维度测试与评估平台。项目完全由静态网页技术（HTML / CSS / JavaScript）构建，无任何后端依赖，能够无缝适配桌面端与移动端，并支持一键部署至 GitHub Pages 等静态托管平台。

## 核心设计与特性

- **黑白极简美学**：精心调配的 HSL 单色配色方案与微动效（Micro-animations），提供高端且极具未来感的视觉体验。
- **双色主题切换**：支持深色（Dark Mode）与浅色（Light Mode）主题切换，并保存至本地浏览器存储（LocalStorage）。
- **零后端静态架构**：所有测试与评估逻辑完全在客户端浏览器中执行，保证了数据隐私与极快的加载速度。
- **全响应式布局**：无论是宽屏显示器还是移动设备，页面元素均能自适应完美呈现。

## 评估模块介绍

本平台包含以下 **6 个活跃的测试评估模块**：

1. **[智商与认知测试 (Intelligence)](./Intelligence/index.html)**
   评估逻辑推演、空间想象、数字模式识别以及多维认知加工能力，采用标准智力分布曲线及渐进式难度设计。
2. **[行为与决策倾向评估 (BaDC)](./BaDC/index.html)**
   探查风险决策倾向、非理性偏差控制及博弈情境下的选择逻辑，量化决策边界的稳定性。
3. **[依存与独立性测试 (ManMom)](./ManMom/index.html)**
   基于亲密关系动力学模型，诊断个体在社会依存、家庭纽带（如妈宝特质）及自我自主性之间的平衡度。
4. **[高中物理竞赛测试 (PhyContest)](./PhyContest/index.html)**
   在高速重力下落与引力轨道模拟下测试瞬时物理路径选择与心算反应能力。
5. **[舒尔特方格测试 (ShultGrid)](./ShultGrid/index.html)**
   经典的专注力评估与训练工具，通过动态高强度搜寻模式测算视觉搜索和注意力集中的水平。
6. **[数字华容道 (Klotski)](./Klotski/index.html)**
   经典滑块拼图游戏，用于测试空间逻辑推导、路径规划与复杂问题统筹解决能力。

## 快速开始

本项目为纯静态网站，无需安装任何复杂的依赖。

### 本地运行

1. 双击直接在浏览器中打开项目根目录下的 **[index.html](./index.html)** 即可运行。
2. 或者，您也可以在项目根目录下通过本地服务器启动（推荐）：
   ```bash
   # 使用 Node.js 的 serve 模块
   npx serve .

   # 或者使用 Python 内置服务器
   python -m http.server 8000
   ```

### 部署

由于是纯静态页面，只需将整个项目文件夹推送到您的 GitHub 仓库并启用 **GitHub Pages**，或者上传至任意静态网页托管服务即可。
